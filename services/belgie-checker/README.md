# Проверка сайта в БелГИЭ (`fastup.by/tools/belgie-checker`)

Бесплатный онлайн-инструмент от агентства **[FastUp](https://fastup.by/)** для проверки регистрации белорусских сайтов в государственном реестре БелГИЭ по требованиям Указа №60.

🔗 **Рабочий инструмент:** [https://fastup.by/tools/belgie-checker](https://fastup.by/tools/belgie-checker)

## Что проверяет сервис за один запрос
1. **Реестр БелГИЭ:** зарегистрирован ли домен в официальной базе, его регистрационный номер и дата регистрации.
2. **Владелец и УНП:** на какое юрлицо или ИП оформлен сайт, 9-значный УНП (с быстрым переходом в [проверку контрагента по УНП](https://fastup.by/tools/unp-checker)) и статус плательщика в МНС РБ.
3. **Хостинг и локация сервера:** страна физического размещения сервера по IP-адресу и название белорусского хостинг-провайдера.
