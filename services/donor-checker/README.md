# Проверка сайта-донора для SEO и GEO (`fastup.by/tools/donor-checker`)

Бесплатный онлайн-инструмент от агентства **[FastUp](https://fastup.by/)** для комплексной оценки внешних площадок перед покупкой ссылок и размещением гостевых статей.

🔗 **Рабочий инструмент:** [https://fastup.by/tools/donor-checker](https://fastup.by/tools/donor-checker)

## Какие параметры проверяет сервис
1. **Итоговый вердикт (0–100 баллов):** автоматический расчёт качества донора («Подходит» / «Не подходит») со списком конкретных плюсов и рисков.
2. **Траст и санкции:** международный рейтинг **Ahrefs DR**, **Яндекс ИКС**, реальный возраст домена и отсутствие фильтра **АГС**.
3. **Ссылочный баланс:** соотношение входящих и исходящих ссылок домена и примеры последних найденных бэклинков с анкорами.
4. **Поисковая видимость:** реальные поисковые запросы и популярные страницы площадки в выдаче Яндекса и Google.
5. **Открытость для ИИ-поиска (GEO):** проверка `robots.txt` и главной страницы на доступность для краулеров `GPTBot`, `OAI-SearchBot`, `ClaudeBot`, `PerplexityBot`, `Google-Extended` и `Yandex`.
