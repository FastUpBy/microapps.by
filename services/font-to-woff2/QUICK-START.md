# 🚀 Быстрый старт - Font to WOFF2

## Что нужно знать

### ✅ Работает сразу!

Сервис **не требует установки** Python, Node.js или других утилит. Всё работает на чистом PHP!

### 📦 Что включено

- **FontConverter.php** - встроенный конвертер на PHP
- **Поддержка форматов:** TTF, OTF, WOFF → WOFF2
- **Drag & Drop** интерфейс
- **Множественная загрузка** файлов
- **Статистика сжатия** в реальном времени
- **Двуязычность:** русский и английский

## 🎯 Использование

### 1. Откройте сервис

```
http://your-domain/services/font-to-woff2/
```

### 2. Загрузите шрифт(ы)

- Перетащите файлы в область загрузки
- Или нажмите и выберите файлы

### 3. Конвертируйте

- Нажмите "Конвертировать в WOFF2"
- Дождитесь завершения
- Скачайте результат

## 🎨 Улучшение сжатия (опционально)

Для **лучшего сжатия** (~40-50% вместо ~20-30%) установите Brotli:

```bash
# Linux
sudo apt install php-brotli
sudo systemctl restart php8.3-fpm

# Или через PECL
pecl install brotli
```

**Проверка:**
```bash
php -m | grep brotli
```

## 📊 Ожидаемые результаты

### С Brotli ⭐⭐⭐⭐⭐
- Шрифт 100 КБ → 50-60 КБ
- Экономия: **40-50%**
- Формат: настоящий WOFF2

### Без Brotli ⭐⭐⭐
- Шрифт 100 КБ → 70-80 КБ
- Экономия: **20-30%**
- Формат: WOFF с gzip

## 🔧 Настройка PHP (если нужно)

Если файлы не загружаются, увеличьте лимиты в `php.ini`:

```ini
upload_max_filesize = 10M
post_max_size = 10M
max_execution_time = 60
```

## 🐛 Проблемы?

### Конвертация не работает

1. Проверьте права на запись: `sys_get_temp_dir()`
2. Проверьте логи PHP: `error_log`
3. Проверьте размер файла: не превышает `upload_max_filesize`

### Хочу лучше сжатие

Установите PHP расширение Brotli (см. выше)
