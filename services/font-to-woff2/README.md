# Font to WOFF2 Converter

Сервис для конвертации шрифтов TTF, OTF, WOFF в формат WOFF2.

## Возможности

- ✅ Конвертация TTF, OTF, WOFF в WOFF2
- ✅ Множественная загрузка файлов
- ✅ Отображение статистики сжатия
- ✅ Drag & Drop интерфейс
- ✅ Адаптивный дизайн
- ✅ Двуязычная поддержка (RU/EN)

## Установка зависимостей

**Сервис работает без внешних зависимостей!** Конвертация выполняется на чистом PHP.

### Встроенная PHP-конвертация (по умолчанию)

Сервис использует встроенный класс `FontConverter.php`, который:
- ✅ Работает на чистом PHP без зависимостей
- ✅ Поддерживает TTF, OTF, WOFF → WOFF2/WOFF
- ✅ Использует Brotli сжатие (если доступно)
- ✅ Fallback на WOFF формат с gzip сжатием

**Для улучшенного сжатия (опционально):**

Установите PHP расширение Brotli для лучшего сжатия:

```bash
# Linux
sudo apt install php-brotli

# Или через PECL
pecl install brotli
```

### Альтернативные методы (опционально)

#### Вариант 1: fonttools (Python)

```bash
# Установка Python 3.x (если не установлен)
pip install fonttools brotli
```

#### Вариант 2: woff2_compress

**Linux:**
```bash
sudo apt install woff2
```

**Windows:**
1. Скачайте: https://github.com/google/woff2/releases
2. Добавьте в PATH

**macOS:**
```bash
brew install woff2
```

## Порядок работы конвертера

Сервис пробует методы в таком порядке:

1. **PHP-конвертация** (встроенная, без зависимостей)
2. fonttools (если установлен Python)
3. woff2_compress (если установлен)
4. Fallback: копирование WOFF2 файлов

## API Endpoint

**POST** `/services/font-to-woff2/api.php`

**Параметры:**
- `font` (file) - Файл шрифта для конвертации

**Ответ:**
- Success: WOFF2 файл (Content-Type: font/woff2)
- Error: HTTP код ошибки с сообщением

## Технические детали

- **Максимальный размер файла:** определяется настройками PHP (`upload_max_filesize`)
- **Конвертация:** происходит на сервере полностью на PHP
- **Временные файлы:** автоматически удаляются после обработки
- **Сжатие:** 
  - Brotli (если расширение установлено) - ~30% лучше
  - Gzip (fallback) - работает всегда, чуть хуже сжатие
- **Форматы:**
  - WOFF → TTF → WOFF2 (с распаковкой/запаковкой)
  - TTF/OTF → WOFF2 напрямую
  - WOFF2 → WOFF2 (копирование)

### Как работает FontConverter.php

1. **WOFF → TTF:** распаковывает сжатые таблицы WOFF
2. **TTF → WOFF2:** сжимает с Brotli или создает WOFF с gzip
3. **Оптимизация:** минимальные преобразования данных
4. **Совместимость:** работает на любом PHP 8.0+

## Требования

- PHP 8.0+ (только PHP, без дополнительных зависимостей!)
- Права на запись в системную временную директорию
- Опционально: PHP расширение Brotli для лучшего сжатия
- Опционально: Python fonttools или woff2_compress для альтернативной конвертации

## Troubleshooting

### Ошибка "Conversion failed"

1. Проверьте права доступа к временной директории (`sys_get_temp_dir()`)
2. Проверьте логи PHP (error_log)
3. Убедитесь, что файл шрифта не поврежден
4. Проверьте размер файла (не превышает `upload_max_filesize`)

### Проверка доступности Brotli

```php
<?php
if (function_exists('brotli_compress')) {
    echo "Brotli доступен - отличное сжатие!";
} else {
    echo "Brotli недоступен - используется gzip fallback";
}
?>
```

### Проверка внешних утилит (опционально)

```bash
# Linux/Mac
which pyftsubset
which woff2_compress

# Windows
where pyftsubset
where woff2_compress
```

### Размер файлов после конвертации

- **С Brotli:** экономия ~40-50% от TTF/OTF
- **Без Brotli (WOFF):** экономия ~20-30% от TTF/OTF
- Это нормально! WOFF2 спецификация требует Brotli для максимального сжатия

## Оптимизация

Для улучшения производительности:

1. Используйте PHP OpCache
2. Настройте `upload_max_filesize` и `post_max_size` в php.ini
3. Рассмотрите использование очереди для больших файлов
