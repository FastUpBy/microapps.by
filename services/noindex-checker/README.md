# Проверка закрытия страницы от индексации (`fastup.by/tools/noindex-checker`)

Бесплатный онлайн-инструмент от агентства **[FastUp](https://fastup.by/)** для экспресс-проверки любой веб-страницы на запреты индексации для поисковых систем и ИИ-краулеров.

🔗 **Рабочий инструмент:** [https://fastup.by/tools/noindex-checker](https://fastup.by/tools/noindex-checker)

## Что проверяет утилита
1. **HTTP-ответ и редиректы:** итоговый статус-код страницы и цепочка перенаправлений.
2. **Мета-теги и HTTP-заголовки:** наличие `noindex` или `nofollow` в `<meta name="robots">`, `<meta name="googlebot">`, `<meta name="yandex">` и заголовке `X-Robots-Tag`.
3. **Канонический адрес:** совпадение `rel="canonical"` с проверяемым URL.
4. **Доступность в `robots.txt`:** открыта ли страница для роботов Google, Яндекса, ChatGPT (`GPTBot`, `OAI-SearchBot`), Perplexity (`PerplexityBot`) и Claude (`ClaudeBot`).
