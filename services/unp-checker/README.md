# Проверка контрагента по УНП и названию (`fastup.by/tools/unp-checker`)

Бесплатный онлайн-сервис от агентства **[FastUp](https://fastup.by/)** для быстрой проверки компаний и индивидуальных предпринимателей Республики Беларусь по базам МНС РБ и ЕГР.

🔗 **Рабочий инструмент:** [https://fastup.by/tools/unp-checker](https://fastup.by/tools/unp-checker)

## Возможности инструмента
1. **Поиск по 9 цифрам УНП или названию компании:** введите номер УНП либо название организации / фамилию ИП. При нескольких совпадениях сервис выводит список юрлиц со статусами и адресами для выбора в один клик.
2. **Прямые данные из МНС РБ и ЕГР:** актуальный статус плательщика («Действующий» или «Ликвидирован»), полное и краткое наименование, дата постановки на учёт, инспекция МНС и юридический адрес.
3. **Копирование реквизитов для договора:** кнопка «Скопировать реквизиты» формирует готовый текстовый блок для вставки в договор, счёт или акт.
